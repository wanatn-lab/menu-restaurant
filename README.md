# คู่มือใช้งานเว็บไซต์ "จิ๊นโค สุพรรณบุรี"

> **หมายเหตุแบ็คอัพ:** ไฟล์ในโฟลเดอร์นี้เป็นซอร์สโค้ดฉบับเต็มของเว็บไซต์ที่รันอยู่จริงที่
> **https://jinko-menu.netlify.app** (ชื่อร้าน จิ๊นโค สุพรรณบุรี) ดึงกลับมาจากเว็บไซต์จริง
> เพื่อเก็บไว้เป็นแบ็คอัพ เผื่ออนาคตอยากแก้ไขเพิ่มเติมหรือย้ายไปโฮสอื่น รูปภาพ SVG ที่เป็น "ภาพจำลอง"
> ทั้ง 7 ไฟล์แนบมาครบ ส่วนรูปถ่ายจริง 15 ไฟล์ที่ใช้ในหน้า `menu-live.html` (photo-kaithod.jpg ฯลฯ)
> ยังคงอยู่บนเว็บไซต์จริงตามปกติ (เว็บไม่ได้ถูกลบหรือย้าย) หากต้องการไฟล์รูปเหล่านั้นด้วย
> แจ้งได้ และเนื้อหาเมนูไลฟ์ที่แสดงจริงตอนนี้มาจาก Google Sheet ที่เชื่อมไว้แล้ว (ดู `js/menu-live.js`)
> ไม่ได้อยู่ในไฟล์เหล่านี้

เว็บไซต์นี้เป็นไฟล์ HTML/CSS ล้วน (ไม่ต้องใช้ฐานข้อมูลหรือ backend) พร้อมอัปโหลดขึ้นโฮสติ้งได้ทันที

## โครงสร้างไฟล์
```
timely-bunny-site/
├── index.html                          หน้าแรก
├── menu.html                           เมนูอาหาร
├── about.html                          เกี่ยวกับเรา
├── blog.html                           หน้ารวมบทความ
├── blog-laab-neua-vs-isaan.html        บทความ: ลาบเหนือ vs ลาบอีสาน
├── blog-aharn-neua-suphanburi.html     บทความ: อาหารเหนือสุพรรณบุรี กินที่ไหนดี
├── contact.html                        แผนที่ & ติดต่อ
├── reviews.html                        หน้ารีวิว
├── menu-live.html                      เมนูไลฟ์ (ดึงข้อมูลสดจาก Google Sheet)
├── css/style.css                       สไตล์ชีตหลัก (ใช้ร่วมกันทุกหน้า)
├── js/menu-live.js                     สคริปต์ดึงเมนูจาก Google Sheet
├── images/*.svg                        ภาพจำลองไอคอนจานอาหาร (7 ไฟล์)
├── คู่มือ-เมนูไลฟ์.md                   คู่มือตั้งค่า Google Sheet สำหรับหน้าเมนูไลฟ์
├── robots.txt                          กติกาให้ crawler เข้าถึงเว็บ (เปิดให้ AI crawler ด้วย)
└── sitemap.xml                         แผนผังเว็บสำหรับส่ง Search Console
```

## Deploy ทับเว็บเดิม (เว็บเดียวกับที่ใช้อยู่)

ต้องมีสิทธิ์เข้าถึงบัญชี Netlify ที่เป็นเจ้าของไซต์ `jinko-menu` ก่อน แล้วรัน:

```bash
cd timely-bunny-site
netlify link          # เลือกไซต์ jinko-menu
netlify deploy --prod
```

## Deploy ขึ้นโฮสอื่น / เป็นเว็บใหม่ทั้งหมด

เว็บนี้เป็น HTML/CSS/JS ธรรมดา ไม่ผูกกับ Netlify เลย เอาทั้งโฟลเดอร์ไปวางบนโฮสไหนก็ได้ทันที
(Netlify, Vercel, Cloudflare Pages, หรือโฮสไทยทั่วไป) ไม่ต้องแก้อะไรเพิ่ม

## สิ่งที่ต้องทำก่อนเปิดเว็บจริง (Checklist)

### 1. จดโดเมนและหาโฮสติ้ง
- แนะนำชื่อโดเมน: `jinko-suphan.com`, `jinkoresto.com`, หรือโดเมนภาษาไทย `จิ๊นโค.com`
- ตอนนี้ทุกไฟล์อ้างอิง URL ไว้ที่ `https://jinko-menu.netlify.app/` (URL จริงที่ใช้อยู่ตอนนี้) — เมื่อได้โดเมนจริง ให้ **หาและแทนที่ (Find & Replace)** ข้อความนี้ทุกไฟล์ (.html, sitemap.xml, robots.txt) ด้วยโดเมนจริง
- ตัวเลือกโฮสติ้งฟรี/ถูกและง่ายสำหรับเว็บไฟล์ HTML ล้วน: Netlify, Vercel, Cloudflare Pages (ลากไฟล์วางแล้วออนไลน์ได้เลย ไม่ต้องมีเซิร์ฟเวอร์)
- ถ้าอยากใช้ผู้ให้บริการไทย: Hostatom, Zicho, ThaiHost ก็ใช้ได้เช่นกัน

### 2. ใส่รูปภาพจริง
ทุกจุดที่มี `<div class="dish-mockup">...</div>` (หรือ `.photo-placeholder` เดิม) ให้แทนที่ด้วย `<img src="images/ชื่อไฟล์.jpg" alt="คำอธิบายรูปมีคีย์เวิร์ด เช่น จิ๊นโค สุพรรณบุรี">` — การใส่ `alt text` ที่มีคีย์เวิร์ดช่วย SEO รูปภาพและ Google Images ได้มาก

### 3. ใส่ราคาจริง
ในไฟล์ `menu.html` แทนที่คำว่า "เริ่มต้น" ด้วยราคาต่อจานจริง

### 4. ตั้งค่า Google Business Profile (สำคัญที่สุดสำหรับ "ติด Google สถานที่แนะนำ")
สรุปสั้นๆ:
1. สร้างโปรไฟล์ที่ business.google.com ด้วยชื่อร้าน
2. ใส่ที่อยู่ ถนนขุนช้าง ต.ท่าพี่เลี้ยง อ.เมืองสุพรรณบุรี ให้ตรงกับในเว็บไซต์ 100% (NAP ต้องตรงกันทุกช่องทาง)
3. เลือกหมวดหมู่หลัก "Northern Thai Restaurant" หรือ "Thai Restaurant" + หมวดรอง 3-5 หมวด
4. ถ้ายังไม่เปิดร้าน ให้ตั้งสถานะ "Opening soon" พร้อมวันที่คาดว่าจะเปิด (ตุลาคม 2569)
5. ยืนยันตัวตน (verify) ตามขั้นตอนที่ Google กำหนด
6. หลังยืนยันแล้ว ให้เอาลิงก์ "ฝังแผนที่" จริงจากโปรไฟล์มาแทนที่ iframe ใน `contact.html`

### 5. ส่ง sitemap เข้า Google Search Console
1. เพิ่มเว็บไซต์ใน Google Search Console (ยืนยันความเป็นเจ้าของโดเมน)
2. ส่ง `sitemap.xml` เข้าไปที่เมนู Sitemaps
3. ใช้เครื่องมือ "URL Inspection" กด Request Indexing ทีละหน้าเพื่อเร่งให้ Google เก็บข้อมูล

### 6. รูปภาพ Open Graph
สร้างไฟล์ `images/og-image.jpg` (ขนาดแนะนำ 1200x630px) ใส่รูปเมนูเด่นหรือหน้าร้าน ใช้แสดงตอนแชร์ลิงก์ในโซเชียล

### 7. หน้าเมนูไลฟ์ (menu-live.html)
เชื่อมกับ Google Sheet เรียบร้อยแล้ว (ดู `js/menu-live.js` บรรทัด `SHEET_ID`) ถ้าจะแก้ไขวิธีตั้งค่าเพิ่มเติม
หรือเปลี่ยนไปใช้ Sheet อื่น ดูขั้นตอนละเอียดในไฟล์ `คู่มือ-เมนูไลฟ์.md`

## หมายเหตุด้าน SEO/GEO ที่ทำไว้ให้แล้ว
- ทุกหน้ามี `<title>` และ `meta description` ที่มีคีย์เวิร์ด อาหารเหนือ / ลาบเหนือ / อาหารเหนือสุพรรณบุรี
- ใส่ JSON-LD structured data: `Restaurant`, `Menu`, `FAQPage`, `Article` ช่วยให้ทั้ง Google และ AI search engine (ChatGPT, Perplexity, Gemini) เข้าใจและอ้างอิงข้อมูลร้านได้ถูกต้อง
- `robots.txt` เปิดให้ AI crawler (GPTBot, ClaudeBot, PerplexityBot, Google-Extended) เข้าถึงได้ ซึ่งจำเป็นสำหรับ GEO
- บทความทั้งสองใช้โครงสร้าง "ตอบคำถามใน 200 คำแรก" (TL;DR) ตามหลัก GEO ปี 2026 เพื่อให้ AI engine ดึงคำตอบไปอ้างอิงง่าย
- **ห้ามใส่คะแนนรีวิว/AggregateRating ปลอมเด็ดขาด** — ใส่เฉพาะรีวิวจริงหลังเปิดร้านเท่านั้น ไม่งั้นจะผิดนโยบาย Google และอาจถูกลงโทษ (penalize)
